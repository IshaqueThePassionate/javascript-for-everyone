
# DOM (Document Object Model)

The Document Object Model (DOM) is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. The DOM represents the document as nodes and objects; that way, programming languages can interact with the page.

---

## Topics You’ll Cover

### **[01_dom_manipulation](01_dom_manipulation/)**
Learn how to target, inspect, and modify HTML elements on the page. Master element selectors (`getElementById`, `querySelector`), updating text and attributes, manipulating styles, navigating the DOM tree, and adding or removing elements dynamically[cite: 23, 24].

### **[02_dom_events](02_dom_events/)**
Discover how to make web pages interactive by handling user actions. Explore `addEventListener`, mouse and keyboard events, form submissions, and the behavior of the `this` keyword inside event handlers[cite: 25, 26].

### **[03_practice_and_assignments](03_practice_and_assignments/)**
Work through hands-on activities, practical challenge questions, and mini-projects designed to reinforce core DOM concepts and event-driven patterns[cite: 24, 25, 26].
